فایل‌های این بسته شامل ۷ صفحهٔ شعر هستند که متنشان از گفت‌وگوهای در دسترس جمع‌آوری شده:
1. بدتر تو ز هرچه مار اِگردی
2. خلوت رندانه
3. دود از پی دود
4. شور عشق (بیت آخر با «فراق»)
5. غزل کنایات
6. گله عاشق
7. به نام ایران
8. مشکل گشا نرسد

نکته: ۸ فایل HTML شعر در بسته وجود دارد؛ هر شعر یک صفحهٔ مستقل دارد. فایل‌ها را در ریشهٔ مخزن GitHub بارگذاری کن. برای اینکه شعرها از صفحهٔ اصلی سایت هم قابل دسترسی شوند، بعداً باید پیوند هر صفحه در index.html اضافه شود.
